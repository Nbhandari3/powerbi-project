# powerbi-project
# COVID-19 Global Dashboard 🦠

> Built with Microsoft Power BI

A comprehensive COVID-19 data analysis dashboard built in Power BI, 
visualizing global pandemic trends across 3 analytical views.

---

## Dashboard Pages

### 1. 🌍 Global Overview
High-level snapshot of the pandemic worldwide — total cases, deaths, 
and recoveries across all countries and time periods.

### 2. 🔍 Country Deep Dive
Drill down into individual country data — compare infection rates, 
peak periods, and pandemic timelines side by side.

### 3. ☠️ Death Rate Analysis
Detailed breakdown of mortality rates by country, age group, and 
time period — identifying the hardest hit regions.

## How to Open
1. Download **Power BI Desktop** for free from microsoft.com/powerbi
2. Clone this repo or download the `.pbix` file
3. Open `dashboard.pbix` in Power BI Desktop
4. All data and visuals load automatically
